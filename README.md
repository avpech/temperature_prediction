#### Предсказание температуры сплава
##### Описание
Для оптимизации расходов на электроэнергию металлургическому комбинату необходимо контролировать температурный режим сплава. В проекте разработана модель машинного обучения, предсказывающая финальную температуру стали на основе данных о технологическом процессе: параметрах нагрева, легирования и продувки газом.

В качестве метрики качества используется MAE.

##### Исходные данные

- data_arc — данные об электродах
  - key — номер партии
  - BeginHeat — время начала нагрева
  - EndHeat — время окончания нагрева
  - ActivePower — значение активной мощности
  - ReactivePower — значение реактивной мощности

- data_bulk — данные об объёме сыпучих материалов
  - key — номер партии
  - Bulk1 … Bulk15 — объём подаваемого материала

- data_bulk_time — данные о времени подачи сыпучих материалов
  - key — номер партии
  - Bulk1 … Bulk15 — время подачи материала

- data_gas — данные о продувке сплава газом
  - key — номер партии
  - gas — объём подаваемого газа

- data_temp — данные об измерениях температуры
  - key — номер партии
  - MesaureTime — время замера
  - Temperature — значение температуры

- data_wire — данные об объёме проволочных материалов
  - key — номер партии
  - Wire1 … Wire9 — объём подаваемых проволочных материалов

- data_wire_time — данные о времени подачи проволочных материалов
  - key — номер партии
  - Wire1 … Wire9 — время подачи проволочных материалов

##### Запуск проекта
Предполагается использование anaconda.

Для создания виртуального окружения перейти в каталог проекта и ввести

```conda env create -f requirements.yml```

Активировать виртуальное окружение ```conda activate temp```
